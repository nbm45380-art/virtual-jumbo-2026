# 外食の注文マップ：県別調査の統合メモ（2026-11-25）

## 公開アプリ
- `order-map/index.html`：v2.65。元の全国データを維持して宮城県を統合。
- `order-map/miyagi-research-v265.js`：宮城県第1〜20回の追加調査335レコード（保留43件を含む）。`window.MIYAGI_RESEARCH_V265`を定義。
- `index.html`の `STORES.push(...(window.MIYAGI_RESEARCH_V265||[]))` で読み込み。
- indexの従来データに宮城県の別店舗1件があるため、宮城県のアプリ内総数は336件。内訳：通常表示293件、保留43件。
- 通常表示と保留は分ける。保留は「調査保留」フィルターで参照する仕様。

## 実施した監査
- 宮城県調査原本：第1〜19回329件、第20回6件、合計335件。IDはMY-0001からMY-0335まで連続。
- 調査台帳内のID重複0、正規化店名重複0。名前の一致だけでは同じ施設と決めず、支店名・住所・旧店名を区別。
- 「注文方式未確認」を自動的に「店側端末」とする誤分類を修正。
- 「現金専用有力」と現金専用確定を分離。
- 情報が矛盾する例、LINE友だち追加が必要なQR注文経路と他の注文経路、現金払いの同一客直接記録を分けて表示。

## 次の調査
- 宮城県は一次調査を区切り、未確認事項は後日の再調査対象。原則3回確認して判断できなければ約2か月後に再調査。
- 新しい重点県は岩手県。2026-11-25に第1回11レコードの調査台帳を作成済み。岩手県分はまだアプリ未統合。
- 岩手県も「スマホ完結」「スマホ注文＋現金払い」「現金必須」「通常時の口頭代替」「LINE登録が注文に必要か」を重点的に確認。

## 更新時の注意
1. ユーザー自身のスマホ注文と店舗の券売機・備付タブレットを混同しない。
2. 店舗の決済方法と、同一利用者が実際に支払った方法を区別する。
3. LINE友だち追加、LINEログイン、クーポン取得用の任意登録を分ける。
4. 通常時の口頭注文、初回ドリンクだけの口頭注文、通信障害時の口頭受付を分ける。
5. 注文用QR、決済用QR、通販用QR、LINEショップカード用QRを混同しない。
6. 支店・移転・改称・閉店・変更時期を記録し、旧店の注文方式を無条件で継承しない。
